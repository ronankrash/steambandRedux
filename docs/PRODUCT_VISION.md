# Product Vision — Brassdeep

## Intended experience

A handheld-friendly Windows roguelike where every step matters. You explore a subterranean industrial underworld of stone, oxidized brass, steam pipes and abandoned machinery. Character builds matter: races, classes, skills, firearms, crafting and unusual foes create systemic depth inspired by Steamband’s design density — expressed through an original isometric pixel presentation.

## Design pillars

1. **Deterministic depth** — seeded runs, readable rules, rebuildable outcomes.
2. **Controller-first tactility** — ROG Ally / handheld PC as the primary play surface.
3. **Isometric clarity** — Drova-like readability without copying Drova content.
4. **Data-driven content** — races, items, monsters and recipes as validated definitions.
5. **Honest architecture** — simulation never depends on animation or UI nodes.

## Target platform

- Windows x86-64
- 1280×720 and 1920×1080
- Seven-inch handheld usability for UI text and prompts

## Explicit non-goals (this milestone)

- Real-time combat
- Full Steamband feature parity
- Multiplayer
- Steamworks integration
- Final production art
- Porting legacy C sources into Godot

## Provenance

Steamband materials under `reference/steamband/` inform design only. Licensing for commercial reuse of that corpus is unresolved; Brassdeep content and code are newly authored.
